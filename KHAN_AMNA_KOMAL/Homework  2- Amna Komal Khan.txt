TEST VECTORS AND ARCHITECTURAL SETTINGS

- Architecture: 16-bit Single-Cycle RISC Load-Store AI Processor

- Instruction Set: 4 instructions (Load, Store, MOV, MAC) with 3-bit Opcode

- Register File: 16 entries x 16-bit (R0 hardwired to 0)

- Memories: 32 x 16-bit Instruction Memory (icmem) and 32 x 16-bit Data Memory (dcmem)

- Clock Frequency: 100 MHz (10 ns clock period, 13 clock cycles per 2-input neuron Y = x1*w1 + x2*w2 + b)

- Test Scenarios (Preloaded in Data Memory via Testbench):

  * Case 1 (Baseline Positive) : x = (2, 3), w = (4, 5), b = 1

  * Case 2 (Signed Negative)   : x = (-6, 3), w = (4, -5), b = 10

  * Case 3 (Positive Overflow) : x = (200, 150), w = (100, 100), b = 0

  * Case 4 (Negative Underflow): x = (-200, -150), w = (100, 100), b = 0
