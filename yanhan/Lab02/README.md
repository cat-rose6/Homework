# 16 位单周期处理器

[ai_core.sv](ai_core.sv) 使用 SystemVerilog 实现了一个支持四条指令的处理器。顶层模块 `ai_core_top` 连接译码器、寄存器堆、指令存储器、数据存储器和乘加单元。处理器每个时钟周期执行一条指令，有 16 个 16 位寄存器，其中 `R0` 恒为零。指令存储器和数据存储器各有 32 个字。

| 指令 | 功能 |
| --- | --- |
| `LOAD` | 将基址寄存器与 5 位偏移相加，取低 5 位作为字地址，把该地址的数据读入目标寄存器。 |
| `STORE` | 将 `rs2` 的值写入数据存储器，字地址取自 `rs1` 的低 5 位。 |
| `MOV` | 将 9 位立即数符号扩展到 16 位，写入目标寄存器。 |
| `MAC` | `funct=1` 时用 `rs1` 初始化累加器，`funct=0` 时累加有符号乘积 `rs1 × rs2`。两种操作都把结果的低 16 位写回累加器和目标寄存器。 |

## 仿真结果

[tb_ai_core.sv](tb_ai_core.sv) 装载指令并运行神经元计算 `y = x1 × w1 + x2 × w2 + b`。测试程序将结果写入数据存储器的字地址 13，再读回并与期望值核对。以下四组用例均在 ModelSim SE-64 2020.4 中通过。

| 输入 (x1, x2) | 权重 (w1, w2) | 偏置 b | 读回值（有符号） | 16 位编码 |
| --- | --- | ---: | ---: | --- |
| (3, 4) | (5, 6) | 7 | 46 | `0x002E` |
| (-3, 4) | (5, -6) | -7 | -46 | `0xFFD2` |
| (0, 0) | (0, 0) | -256 | -256 | `0xFF00` |
| (255, 255) | (255, 255) | 255 | -767 | `0xFD01` |

最后一组的数学结果为 130305，保留低 16 位得到 `0xFD01`，按有符号补码解释为 -767。

在项目目录下运行以下命令可复现仿真。

```powershell
vlib work
vlog -sv ai_core.sv tb_ai_core.sv
vsim -c work.tb_ai_core -do "run -all; quit -f"
```
