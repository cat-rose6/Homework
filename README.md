# System-on-Chip Design — Course Homework

This repository collects homework submissions for the System-on-Chip Design course.

## Submission Instructions

1. Fork this repository to your own GitHub account.
2. Open the folder corresponding to your name.
3. Create a subfolder for each assignment, such as Lab01 or Lab02.
4. Upload your source code, report, and instructions for running the code.
5. Open a Pull Request targeting the main branch of this repository.
6. Use the following Pull Request title format: Lab01 - YourName.
7. Wait for the instructor or teaching assistant to review and merge your submission.

Only modify files inside your own folder.


## Lab 01

### Requirements

1. Derive the backpropagation equations for W3.
2. Train a neural network with three linear layers on the MNIST dataset.
3. Report the model's classification accuracy.

### Reference Tutorial

https://docs.pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html

The tutorial uses a CNN and the CIFAR-10 dataset.
Adapt it to use a neural network with three linear layers and the MNIST dataset.
