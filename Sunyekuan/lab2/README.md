# Lab 2：16 位单周期 RISC 处理器

本实现对应 `lec07-risc.pptx` 第 14–26 页。第 14–16 页定义指令格式、四条指令和神经元例程；第 17–19 页给出寄存器堆、存储器、MAC 和 MUX 的起始代码；第 20–25 页给出顶层连线步骤，第 25 页要求写译码器。以 `rtl/ai_core_top.v` 为顶层，每个运行周期完成一条指令。`rtl/decoder.v` 可以单独查看。

## 1. 指令格式与译码

指令固定为 16 位，高 3 位 `[15:13]` 是 opcode，寄存器索引为 4 位，通用寄存器共有 16 个，每个宽 16 位。`R0` 读出恒为 0，忽略对它的写入。课件未给出具体 opcode 数字，下表采用本作业自定的编码。

| 指令 | opcode | `[12:9]` | `[8:5]` | `[4:0]` | 执行效果 |
|---|---|---|---|---|---|
| `LOAD rd, rs1, imm5` | `001` | `rd` | `rs1` | `imm5` | `R[rd] ← Mem[(R[rs1]+imm5) mod 32]` |
| `STORE rs1, rs2` | `010` | 保留 | `rs1` | `{rs2[3:0], 保留位}` | `Mem[R[rs1] mod 32] ← R[rs2]` |
| `MOV rd, imm9` | `011` | `rd` | `imm9[8:5]` | `imm9[4:0]` | `R[rd] ← 零扩展后的 imm9` |
| `MAC rd, rs1, rs2, funct` | `100` | `rd` | `rs1` | `{rs2[3:0], funct}` | `funct=0`：`R[rd]` 和 `psum` 同时写入 `psum+R[rs1]×R[rs2]`；`funct=1`：同时写入 `R[rs1]` |

`STORE` 复用 R 型的两个源寄存器字段，保留位按 0 编码；`MAC funct=1` 忽略 `rs2`。数据地址以字为单位，访存只取低 5 位。`MOV` 的 9 位立即数按无符号处理。乘法按 16 位有符号数据解释，乘积和累加结果都保留低 16 位，无饱和和溢出标志。

译码器先用固定切片提取字段，再根据 opcode 生成控制信号。读寄存器端口在各指令中可以得到同一组切片，但只有相应的数据通路会使用其输出。`addr_add_imm` 控制地址是否加偏移，`wb_sel` 选择写回数据。

| 指令 | `reg_wen` | `mem_wen` | `mac_en` | `addr_add_imm` | `wb_sel` |
|---|---:|---:|---:|---:|---|
| `LOAD` | 1 | 0 | 0 | 1 | `00`：数据存储器 |
| `STORE` | 0 | 1 | 0 | 0 | `11`：无写回 |
| `MOV` | 1 | 0 | 0 | 0 | `10`：立即数 |
| `MAC` | 1 | 0 | 1 | 0 | `01`：MAC 结果 |
| 未分配 opcode | 0 | 0 | 0 | 0 | `11`：无写回 |

## 2. 课件代码的补全

- **MAC 偏置初始化。** 第 15 页指定 `funct=1` 的操作数是 `rs1`，第 16 页的汇编要求下一条乘加从偏置 `b` 开始。第 19 页代码片段在 `funct=1` 时却输出 `rs2` 并清零 `psum`；照抄后续乘加会漏掉偏置。因此这里让 `rd` 与 `psum` 同时装入 `R[rs1]`，覆盖旧累加值。只有执行 `MAC` 时更新 `psum`，中间的 `LOAD`、`STORE`、`MOV` 不会改变它。
- **指令与数据装载。** 指令和数据存储器分别为 32×16 位。保留课件例程的 16 位 PC，显式取 `pc[4:0]` 寻址指令存储器。停机时可以在指定地址装载指令和数据；运行时读取指令并在时钟上升沿写回。持续运行超过 32 条会回到指令存储器的起始地址；本 ISA 无 `HALT`，例程结束后拉低 `run`。
- **低有效复位。** `rst=0` 清零 PC、寄存器堆和 `psum`，存储器保持原内容。`run=0` 时，`inst_wen` 和 `data_wen` 分别在时钟上升沿按外部地址写入指令和数据；`data_out` 可读出 `data_addr` 指定的数据。外部写入期间 PC 和处理器写回均暂停。

## 3. 两输入神经元例程

按课件第 16 页设置 `ADB=4`、`ADX=8`、`ADW=12`、`ADY=16`。仿真写入 `Mem[4]=7`（偏置），`Mem[8]=3`、`Mem[9]=-2`（输入），`Mem[12]=4`、`Mem[13]=5`（权重）。下列机器码保存在 `program/neuron16.hex` 中。

| PC | 机器码（十六进制） | 汇编 | 说明 |
|---:|---|---|---|
| 0 | `6204` | `MOV R1, 4` | 偏置地址 |
| 1 | `2420` | `LOAD R2, R1, 0` | 读偏置 `b` |
| 2 | `8a41` | `MAC R5, R2, -, 1` | 初始化 `R5` 和 `psum` 为 7 |
| 3 | `6208` | `MOV R1, 8` | 输入起始地址 |
| 4 | `640c` | `MOV R2, 12` | 权重起始地址 |
| 5 | `2620` | `LOAD R3, R1, 0` | 读 `x1` |
| 6 | `2840` | `LOAD R4, R2, 0` | 读 `w1` |
| 7 | `8a68` | `MAC R5, R3, R4, 0` | `R5 = 7 + 3×4 = 19` |
| 8 | `2621` | `LOAD R3, R1, 1` | 读 `x2` |
| 9 | `2841` | `LOAD R4, R2, 1` | 读 `w2` |
| 10 | `8a68` | `MAC R5, R3, R4, 0` | `R5 = 19 + (−2)×5 = 9` |
| 11 | `6210` | `MOV R1, 16` | 输出地址 |
| 12 | `402a` | `STORE R1, R5` | 将 9 写入 `Mem[16]` |

## 4. 仿真与复现

使用 Vivado 2018.3 验证。将 Vivado 加入 `PATH` 后，在项目目录中运行：

```powershell
.\run_sim.ps1
```

如未将 Vivado 加入 `PATH`，用 `.\run_sim.ps1 -VivadoBin 'C:/Xilinx/Vivado/2018.3/bin'` 指定自己的安装目录。脚本生成 `results/simulate.log` 和 `results/lec07_risc.wdb`。可用 Vivado Simulator 打开波形数据库，观察 `pc`、`current_inst`、`dut/mac/psum`、`dut/mem_wen` 与 `dut/core_mem_addr`。

本次行为仿真的关键输出：

```text
PC=2: bias loaded into R5 and psum: 7
PC=7: first product plus bias: 19
PC=10: second product added: 9
PC=12: mem[16] = 9
PASS: neuron program and core checks
```

测试平台还检查了暂停时禁止 STORE、`R0` 写入保护、9 位立即数 `511`、5 位偏移 `31`、数据地址回绕、保留 opcode 无写入、重新初始化非零累加器和复位行为。验证范围为 RTL 行为仿真。
